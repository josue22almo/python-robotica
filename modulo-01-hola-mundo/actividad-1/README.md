## Contexto

Un robot no nace encendido: alguien le escribe las instrucciones. Un programa es, exactamente eso, una lista de instrucciones que la máquina sigue en orden.

Vamos a empezar por lo más pequeño que funciona: un programa que escribe algo en la consola.

## Objetivo

Escribir tu primer programa en Python y comprobar que funciona.

## Lo que debes hacer

1. Crea la carpeta `modulo-01-hola-mundo/actividad-1/solucion` y dentro el fichero `hola.py`.
2. El programa tiene que mostrar, en tres líneas:
   - tu nombre,
   - el nombre del robot que quieres construir este curso,
   - una frase de cinco palabras o menos con lo que esperas de esta asignatura.
3. Ejecuta el programa y guarda lo que sale por pantalla en un fichero `hola-salida.txt`, dentro de `solucion/`.

## Entregable

- `solucion/hola.py` con el código.
- `solucion/hola-salida.txt` con la salida de ejecutarlo.

## Criterios de evaluación

| Criterio | Peso |
|---|---|
| El programa se ejecuta y muestra las tres líneas | 60 % |
| La salida está guardada en `hola-salida.txt` | 25 % |
| El código está en `solucion/` y el commit tiene un mensaje claro | 15 % |
